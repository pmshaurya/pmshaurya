# Hi, I'm Shaurya 👋

Senior Product Manager (7.5+ yrs) in enterprise SaaS, building AI workflows that run in production.

I own a portfolio of 25+ integration connectors for regulated life-sciences software. As my team's AI Champion, I shipped three agentic workflows to production:

- **Requirements pipeline:** chained PRD → URS → FRS agents with human sign-off gates. First drafts went from 2–3 days to hours.
- **Post-release automation:** 7 manual handoffs across 5 systems became one command. 60 min → 2 min per release.
- **Client release notes:** a template-driven agent with a review gate. Days → 30 minutes, fully in-house.
